# Reader mode

Reader is a reversible, local article view for the focused normal/split, Peek, or Quick webpage. Source DOM, forms, history, and scroll remain mounted and unmodified. Extraction uses Mozilla Readability 0.6.0 on a clone in an isolated content world; the extraction result is serialized through an allowlist of structural tags and HTTP(S) links. A separate nonpersistent WKWebView has no extension controller, no message handlers, no article JavaScript, no subresource access, and restrictive CSP. Native controls offer light/sepia/dark, serif/sans, text size, content width, and exit. Links exit Reader and navigate the original source through the normal WebKit policy/protection path.

Alternatives considered: replacing the source DOM loses forms and is rejected; a native text-only renderer loses useful article structure; an isolated allowlist HTML renderer preserves structure with a small auditable boundary. This last approach is the implementation choice, under the user's instruction to proceed without routine design questions.

Each reader session captures its source view, document/presentation identity, profile, URL, window, and store. Navigation, disposal, ownership transfer, profile clearing, close, or timeout revokes the session and discards pending callbacks. Sessions are per webpage and memory-only. HTTP(S) HTML pages only; PDFs, privileged/extension documents, empty/short/nonarticle/oversized documents and failed extraction receive honest native feedback. No remote service, telemetry, accounts, or keys. Inline image alt/captions are retained; remote images/media and cross-origin iframe content are intentionally omitted. Full pixel review awaits the unlocked dedicated VM; this increment does not complete the broader browser project.

macOS 14+ remains supported. No version, engine, signing, release, or publication changes. The standard manual build and SwiftPM build must carry the pinned resources and licenses. Extension Reader flags stay rejected until separately supported.

Reader's Cmd-F searches the visible article and guards stale callbacks. Escape closes article find before exiting Reader. Zoom applies to Reader while active. Existing page output remains source-owned and its native menu names explicitly say Original Page while reading. Link clicks, Shift-click Peek, and Command/middle-click new pages use the captured source profile and normal website protection; renderer-created windows never receive the renderer's inert configuration or opener relationship. Reader theme is scoped to its SwiftUI subtree rather than changing the original window appearance.
