# Sidebar saved tabs, folders and window closure

User steering: make Cmd-W close the current tab, close an empty browser window without quitting Alcove, separate saved/bookmarked tabs like Arc, and support creating folders and adding tabs. Existing smooth sidebar behavior should be preserved. Existing autonomous/in-place-main and design-question opt-out remain in force; no extra approval gate or per-task agent.

Use a labeled Pinned section above a separately scrolling Today section. Favorites remain compact profile-wide tiles above the Space. Pinned tabs/folders stay visible when Today scrolls; each saved area has a bounded independent scroll region so large libraries/large text/short windows keep Today and the footer reachable. Add New Folder in the pinned header, folder context actions, drop targets and tab Move to Folder menus. Folder definitions persist even when empty, per Space, alongside the existing tab.folder membership and collapsed state. Normalize bounded names, reject blank/control/duplicate names, preserve folder order and migrate existing tab memberships without moving another Space/profile's data. Removing a folder keeps its tabs pinned and ungrouped. Private folders stay temporary.

Bookmarking still saves the Library entry and also pins the source page. Reuse the actual main tab and its live view; Quick/Peek bookmarking may create a saved pin in the captured owner Space without closing/reloading that compact page. Preserve existing Favorites without duplicating them. Source account/Space must be captured, not whichever profile happens to be active later.

Cmd-W closes a visible panel or Peek first. Otherwise close the focused tab/page; preserve saved pin/Favorite definitions. Close the source browser window when the current Space has no regular website tabs left, including the initial blank window or locked/loading window. Other Spaces/pins remain saved. Quick Browse keeps its actual window-close behavior. Use NSWindow.performClose and the existing owner lifecycle; never terminate NSApplication. A split's other regular pane keeps the window open.

Approach chosen by agent: extend the current native Store/sidebar and existing pinned/folder models. A Library-only bookmarks panel misses persistent visibility; a single combined tab scroller hides saved tabs; dummy tabs for empty folders corrupt tab semantics. Add optional Space.folders definitions within the developing format5 model, retaining legacy memberships. No framework/dependency/entitlement/Keychain-policy changes, macOS14 minimum and stable Visual Four identity.

Verification includes real native menu routing through owned hidden windows, actual live-view preservation when pinning/bookmarking, encrypted folder round trips, profile/private isolation, failed-save atomicity, drop/menu routing and short/large-text layout with populated saved/daily tabs. Then the full frozen suite, both optimized architectures and native CUA checks before updating the local test build. The unfinished extension plan and full browser goal remain active; do not publish a misleading completed-extension release or claim perfection.

Implementation ruling: normal session repair materializes legacy tab-derived folder names into ordered definitions before saving, so old folders also survive losing their final child. Layout validation uses the existing normalized maximum text scale1.35; this change does not raise the global appearance cap.
