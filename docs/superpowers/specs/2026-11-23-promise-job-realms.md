# Promise continuation realms

Alcove must preserve the page owning asynchronous JavaScript code. The original uBlock ZIP/CRX qualification intermittently navigates its options page from dashboard.html to background.html#settings.html. Native traces show a dashboard lexical global with a background entry global during WebCore's microtask checkpoint. VM867 now reproduces this deterministically with two ordinary same-origin loopback pages: pending foreign-promise then, await and Promise.all all navigate to background.html instead of options.html. Same-page asynchronous and synchronous cross-page controls pass on both system WebKit and the exact 15-patch research runtime.

ECMAScript's [NewPromiseReactionJob](https://tc39.es/ecma262/multipage/control-abstraction-objects.html#sec-newpromisereactionjob) selects the handler function's realm, including bound/proxy targets; revoked proxies fall back to the current realm. HTML's [HostEnqueuePromiseJob](https://html.spec.whatwg.org/multipage/webappapis.html#hostenqueuepromisejob) uses that realm as the job's entry settings. The pinned JavaScriptCore scheduler currently records the settling global unconditionally.
