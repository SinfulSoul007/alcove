Private windows ignore normal routing and cannot edit this normal configuration.

Compare copied-address representations locally, case-insensitively with stable locale semantics. Canonicalize scheme/host/default ports, supply root slash, normalize literal/escaped dot path segments and retain other path/query/fragment escaping. A Contains prefix with no supplied path retains its literal prefix boundary. Contains matches the full canonical address; a standalone hostname pattern is canonicalized too. Full-scheme equality remains scheme-specific. A scheme-less Equals condition is prepared separately for HTTP and HTTPS, so explicit ports are normalized in the incoming scheme’s context; duplicate detection compares both representations. Tests pin these choices. No network occurs during edits, matching or preview.

## Destination and account policy

External HTTP(S) links evaluate rules, then the configured default. A named Space explicitly chooses its profile and overrides remembered-host profile choices. Quick Browse and Most Recent Space use the remembered profile, otherwise the active profile. Most Recent chooses that profile's valid last-used Space, then current matching Space, then another matching Space, then creates one. A remembered paused profile blocks unless an explicit named-Space destination supersedes it. Missing legacy default uses quickBrowseExternalLinks; setters mirror that flag for existing controls.

Normal archive Restore evaluates a matching rule; without one it returns to its valid original same-profile Space, then the same-profile fallback. Quick Browse archive's explicit Quick Browse button keeps its source account and compact destination; Open in Space participates in rules. Closed records can load in a rule's different profile with fresh views/cookies. Remove the source archive only in the same durable commit that creates its destination; failure changes nothing.

Opening a Peek evaluates rules unless an explicit destination was chosen. Quick/Recent preserve its known source profile; a named Space can select another profile. Same-profile Space or compact handoff retains the actual view, form, scroll and history. Cross-profile handoff requires reload consent and never copies website storage. Capture Peek lifetime UUID, source document identity, URL, profile, resolved destination and rule snapshot; revalidate after consent. Closed/replaced/navigating source, edited rule, reassigned/removed/paused target, shutdown or changed window cannot apply stale consent. Cancellation creates no tab/Space/window and leaves the preview intact. Native prompts are window-bound, with an injected presentation seam for owned tests.

Automatic Space openings must not destroy an unrelated primary Peek. Build its same-profile ordinary-tab preservation and the routed page in one candidate document, then move its actual view only after a successful save. Retain form/history and initial requested URL even before its first commit. Do this for external Space dispatch, archive Space restoration and a compact Peek opening while another primary Peek exists; skip preservation when that primary Peek itself is the source being handed off. This is an implementer-chosen data-preserving behavior, not a claimed observed Arc detail. Existing broader beforeunload/close fidelity stays open.

Private actions stay in their temporary owner; no normal rule/default/profile memory/key or files are consulted. Explicit manual destinations override automatic routes. Typing/navigating an existing page and ordinary in-page navigation keep their account; this increment does not rewrite live page navigations.
