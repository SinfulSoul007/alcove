# Site Boosts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Working per-site/profile appearance, CSS/JavaScript customization and element hiding with undo and local sharing.

**Architecture:** BrowserCore owns validated portable values and bounded catalogs inside profile libraries. BrowserStore atomically commits edits and approval snapshots; a generic isolated WebKit bridge resolves live ownership and applies styles/page scripts. SwiftUI exposes source-bound editors and picker controls.

**Tech Stack:** Swift, Foundation, CryptoKit, JavaScriptCore, WebKit, AppKit, SwiftUI; no new dependency.

**Spec:** docs/superpowers/specs/2026-11-09-boosts-design.md

## Global Constraints

- macOS14, metadataformat3, no dependencies/private APIs and exactly the existing six entitlements. Stable live-review bundle and public0.6.2 downloads unchanged. Developing source0.7.0/build12/candidatev0.7.0-preview.1 at final integration; no tag/release.
- Inline/main under standing preference; no additional approval/design/per-task agent gates. One fresh final whole-plan reviewer and one Important/Critical RED→GREEN pass.
- Exact canonical HTTP(S) hostname scope across ports/schemes; WebOrigin rejects ports outside0...65535. Catalog64, CSS64KiB, JavaScript32KiB, name1...80/no controls, selectors64×1...1024UTF8/no controls, aggregate1MiB. Optional #RRGGBB colors, original/system/serif/mono/rounded fonts, textScale0.75...1.75.
- Save before data/DOM publication; separate normal/profile/private data; no user-data fixtures, global input or permission bypass. Portable appearanceJSON excludes JavaScript/approval/IDs/enabled. Explicit code approval and nonce/lifetime/profile/document checks; raw code requires owned syntax compilation and a separate inner async scope.
- Main-frame styles preserve DOM/forms, single runtime bridge per shared UCC, no profile content in injected user scripts. Full original browser/Arc visual/accessibility/compatibility/performance/install gates stay open.

## Review Focus

- Malformed numeric/IDNA/IPv6 hosts or unusable ports must not apply a customization or script to another site.
- Shared popup content controllers and stale same-URL document callbacks must not leak another profile's definitions or retain a closed store.
- Code/source edits and duplicate/late approval replies must not run stale code; body-escape and hoisted identifier payloads must not bypass guards.
- Failed metadata writes, concurrent editor changes, picker clicks during navigation or private/profile changes must preserve data and the original live form.
- Short windows, large text, native menu/panel focus and source-window close must not clip required actions, retarget edits or trap picker mode.
