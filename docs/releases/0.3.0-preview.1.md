# Alcove 0.3 — Arc-style interface preview

This release replaces the earlier generic browser layout with a compact sidebar interface based on inspection of Arc for Mac. It is still an independent WebKit implementation, not Arc source code or full Arc feature parity.

## Download and install

macOS 14+, Apple Silicon and Intel. Download the universal DMG, open it and drag Alcove.app to Applications. A ZIP is also provided. No developer tools are required. SHA256SUMS.txt covers the published artifacts.

**Unsigned preview:** the app is ad hoc signed, not Developer ID signed or notarized. macOS may warn or block it. Do not disable system security protections. This is not a stable or independently audited browser release.

## Interface and experience

- Compact navigation and address field in the sidebar, with native traffic-light controls. The large logo, landing-page design and full-width toolbar are removed.
- Favorites tiles above pinned tabs/folders, a separate Today area, and a scrollable Space dock at the bottom.
- Draggable, bounded sidebar width; native window zoom/resizing; smaller minimum split panes for narrower windows.
- Per-Space Midnight, Lavender, Sage and Sand themes, plus a collapsed sidebar that can be revealed at the left edge.
- Drag tabs between pinned, Today and Favorites sections and into existing folders.
- Stable pinned titles and home URLs: closing a pinned page retains the pin and resets its saved destination.
- Command-T accepts typing immediately, creates no empty tab if cancelled, supports keyboard selection and commands including Pin Tab, Favorite Tab, split view and settings.
- Native Find focus, tab/Space keyboard cycling, and URL navigation/actions directed to the clicked split pane.
- Shift-click links to Peek without losing the underlying tab; replace Peek by Shift-clicking another link, close it or open it as a tab.
- Same-origin site icons are rasterized within WebKit and kept only in window memory. No third-party favicon service is used.

## Reliability and privacy

Keychain startup is noninteractive: if data cannot be unlocked, Alcove opens with a persistent saving-paused banner and an explicit Unlock action. Encrypted data is preserved. Repeated Unlock clicks cannot start overlapping restores. Browsing-data clearing closes Peek and clears in-memory icons. Closing a private window explicitly stops its Peek page.

Normal sessions, bookmarks/history, pinned destinations and Space themes remain locally encrypted. Private windows use nonpersistent website storage and do not save browsing sessions/history. Sidebar width/appearance defaults are ordinary local UI preferences and may be shared across windows, including private windows. WebKit cookie/cache databases are separate from Alcove’s metadata encryption. Downloads saved from private windows remain on disk.

## Validation and remaining work

57 behavioral checks pass, including resize bounds, cross-Space tab moves, pinned close/reset, command matching, split focus, Peek content replacement, duplicate-unlock prevention, encrypted storage and private persistence. Native checks cover sidebar drag resizing, window zoom, command/find focus, real navigation, site icons, Shift-click Peek and replacing its destination. Both CPU architectures compile. The DMG job verifies the ZIP checksum, app signature and CPU slices, mounts the image, and compares the contained executable with the source app.

Not claimed: pixel-for-pixel Arc fidelity, every gesture/animation matched, an independent security audit, Safari-level performance, Intel hardware testing, or minimum-OS/quarantined-download compatibility testing. Extensions, password-manager integration, isolated login profiles, sync, Little Arc external-link windows and signed automatic updates are still missing. Read README.md and SECURITY.md for the security model and other preview limits.
