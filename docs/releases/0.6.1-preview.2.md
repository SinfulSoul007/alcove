# Alcove 0.6.1 — Unsigned Preview

Download the universal DMG and drag **Alcove.app** to Applications. The ZIP contains the same app. Both support macOS14 or newer on Apple Silicon and Intel.

This update improves the sidebar, navigation and compact Quick Browse windows:

- Native window buttons and navigation controls share a measured titlebar baseline, including when the sidebar is hidden. Large text and compact windows keep the actions menu visible.
- The floating sidebar follows current pointer position across fast edge exits, geometry changes and delayed hover events. Menus and resizing hold an already-visible panel open; closing menus or changing windows releases those holds.
- Sidebar pointer bookkeeping no longer publishes unnecessary SwiftUI changes. Websites and sidebar views remain mounted while the panel reveals or hides.
- Escape, focus changes, window changes and overlays cancel an unfinished sidebar resize without saving it. Late drag events cannot revive a cancelled gesture. Double-click resets the width; keyboard arrow steps still work when the grip is focused.

Profiles, website storage, encrypted metadata format3, themes, first-run setup, updates and Quick Browse behavior from0.6 remain available. This update changes neither the document format nor security entitlements. If upgrading from0.5, read the [0.6 migration notes](https://github.com/SinfulSoul007/alcove/blob/main/docs/releases/0.6.0-preview.1.md).

Automated tests cover native geometry, actual browser-root overlay cancellation and pointer/menu/window lifecycle. Never-shown fixtures do not establish onscreen animation, fullscreen, keyboard accessibility or Arc pixel fidelity. Those checks and the broader Arc feature set remain in progress. Safari-equivalent performance and complete security are not claimed.

The app is ad hoc signed, **not Developer ID signed or notarized by Apple**. macOS may block it. Keep system security enabled; if blocked, build from source or wait for a notarized release. This remains an early preview. `SHA256SUMS.txt` detects changed download bytes; it does not establish developer identity.
