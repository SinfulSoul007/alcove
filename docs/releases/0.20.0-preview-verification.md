## Changes

- Local navigation checks against a bundled PhishDestroy Primary catalog, with request-specific Go Back and Continue controls. The original document and forms remain mounted while a request is held. Catalog date/provider and unavailable or stale status are visible. No browsing-address lookup service is enabled.
- Warning ownership follows normal tabs, Split View, Peek, Quick Browse and extension-created website windows. Closing or transferring a page revokes old controls. Closed-tab history keeps the committed page behind a cancelled warning.
- Mouse sidebar resizing no longer leaves a keyboard focus outline. Keyboard interaction restores its visible focus indicator. All twelve welcome-theme choices fit the minimum setup height.
- Publisher-authenticated update offers. Installer verification uses signed byte lengths and SHA-256 hashes; installation remains manual.

The final two source commits repair the sidebar test oracle for returning to a collapsed folder and run its async AppKit fixture under the native event loop. They do not change product sources or relax the four-form preservation assertion. The final native sidebar witness passes 101 checks, including all four unsaved forms.

## Remaining work

Full original uBlock Origin is unsupported in this preview. The separate experimental WebKit engine is not bundled; its qualification and broad Chrome-extension compatibility remain open. Native extension APIs require macOS 15.4 or later.

The local domain list does not inspect page contents, downloaded files, arbitrary subresources, URL paths or IP reputation. Runtime feed updates and broader threat coverage remain open.

This verification does not establish complete Arc visual/feature parity, smoothness under realistic workloads, VoiceOver or OS Reduce Motion behavior, real Intel/minimum-OS compatibility, quarantined installation, Safari-equivalent performance, independent security review, Sync, assisted workflows, Easels/capture, Reader mode or full media/PiP parity. Keep those gates open in the [full browser ledger](../goal/acceptance.md).
