# Alcove 0.2 — Unsigned Preview

A self-contained Mac app for early testing. macOS 14 or newer, Apple Silicon and Intel. No Xcode or developer tools are needed for the download.

## Install

Download the universal ZIP or DMG below. Unzip and move Alcove.app to Applications, or open the DMG and drag the app to Applications. The DMG was subsequently built and mount-verified on GitHub’s macOS runner because the local build environment has no disk-image devices. Compare downloads against SHA256SUMS.txt if desired.

**This preview is ad hoc signed, not Developer ID signed and not notarized by Apple. macOS Gatekeeper may warn or block it. Do not disable Gatekeeper or other system protections. If it cannot run on your Mac, use the source build or wait for a notarized release.**

## New in this preview

- Alcove branding and app icon; installable universal app archives.
- App Sandbox and Hardened Runtime.
- AES-GCM encrypted session, bookmarks, history and preferences with a macOS Keychain key. Startup disables saving on a locked key or unreadable ciphertext to preserve existing data.
- Separate private windows with temporary website storage and no session/history persistence.
- Bookmarks/history/download library, closed-tab restore, find and zoom.
- Pinned-tab folders and optional tab auto-archive; optional lossy background-tab suspension is off by default.
- Website data/history controls, upload picker and request-specific camera/microphone prompts.

## Verification and limits

37 core/browser-store behavioral checks pass, including encrypted storage, modified ciphertext, unavailable/wrong keys, private persistence, archive retention above 500 tabs and closing popups across Spaces. Manual verification on Apple Silicon covered sandboxed web navigation, bookmarks, private history and unchanged normal metadata during a private visit. Universal executable, ZIP structure and ad hoc signature are verified by packaging. Intel is compiled, not yet tested on Intel hardware. The minimum macOS version and a quarantined-download installation flow still need testing.

This is an early preview, not a stable or independently audited daily-driver release. WebKit’s cookies/cache/website storage are separate from Alcove’s encrypted metadata. Private downloads remain on disk. Spaces share website logins. Metadata encryption is not protection against a compromised Mac. No analytics or Alcove sync/account service is included. Sites and DuckDuckGo still receive browsing/search requests.

No extensions, password-manager integration, isolated login profiles, signed auto-updates, complete site-permission UI, location/notification support, or phishing/malware warning service yet. Safari-equivalent performance is not established. Read README.md and SECURITY.md before trying sensitive browsing. Avoid real credentials during initial testing.

The first prototype’s tabs can be added through File → Import Preview Session… by selecting its original session.json. This explicit import leaves that original plaintext file in place.
