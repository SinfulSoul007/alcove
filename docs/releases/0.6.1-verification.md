## Additional release decisions

1. Treat both CI failures as a release gate rather than re-run until green. The owned scheduler-stall probe supplies root-cause evidence; the fixture change preserves bounded failure for a missing transition. This tests behavior, not a frame-time or latency guarantee.
2. Preserve the failed tag and use candidate2/build8. The cost is an unused candidate tag; public0.6 downloads remain intact.
3. Keep the browser source, data formats, timer policy and entitlements unchanged during packaging. Native feel and full browser work remain open; no test result substitutes for those checks.
4. Explicitly retain secure multi-Mac sync, Arc Max workflows and Mini Player/PiP in the full acceptance inventory. These are unfinished scope items, not features added by this preview or permission to transmit browsing content to a service.
