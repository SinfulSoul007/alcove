Alcove 0.6.2 adds native page output to the independent Mac WebKit browser.

- File → Print… (Command-P), Export as PDF…, and Save Page As… (Command-Shift-S, WebArchive) use the visible split pane, Peek, or Quick Browse document. Command-S continues to toggle the sidebar.
- Accepted exports keep writing after their source window closes. Closing or changing a source cannot redirect the result to another page or profile.
- Quit waits quietly for fast output. Longer work offers Wait, Then Quit / Quit Without Finishing / Keep Browsing. A failed save cancels a waiting Quit.
- Failed exports whose source disappeared use a generic result window without the old page's title, URL or destination path.

Download the universal DMG and drag Alcove.app to Applications, or use the ZIP. macOS14+, Apple Silicon and Intel.

This is an ad hoc signed preview, without Developer ID signing or Apple notarization. macOS may block it. Keep system security enabled; build from source or wait for a notarized release if blocked.

Explicitly saved PDFs/WebArchives, printer output and print-system artifacts are outside browser metadata encryption, including in private browsing. Native save/print/Quit dialogs, physical printers, minimum-OS/Intel hardware and quarantined installation need further testing. Opening saved archives in Alcove and website print buttons using window.print() are not implemented. Full Arc feature/visual parity, security audit and Safari performance comparisons remain unfinished.
