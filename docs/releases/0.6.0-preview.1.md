# Alcove 0.6.0 — Unsigned Preview

Download the universal DMG and drag Alcove.app to Applications. The ZIP contains the same app. Both support macOS 14 or newer on Apple Silicon and Intel.

This build adds **Quick Browse**, Alcove’s Little Arc-style external-link workflow. Web links from other apps open in compact, resizable windows when Alcove is your default browser. Reopening the same URL resurfaces its existing window within that profile. Option-Command-N creates a new quick window; Command-N opens the main window, and New Space moves to Control-Command-N.

- Compact address, back/forward/reload, find, progress and profile controls use the existing themes and motion preferences. Shift-click Peek stays over its originating window.
- **Open in Space** preserves the actual live page when staying in the same profile, including forms, scroll, website storage and navigation history. A different profile requires reload consent; cookies are never copied.
- Remember a profile for an exact hostname in the profile picker. A paused remembered profile blocks the link until recovery rather than opening another account. Settings can forget these choices or open external links directly in Spaces.
- Closing the main window keeps the same store alive while quick windows remain. Reopening it reuses that writer. Closing the final window disposes its store; the app remains available in the menu bar until Quit.
- Quick Browse defaults to six-hour inactivity archive, with Off/6/12/24-hour settings. Focused/loading pages, active playback/capture and open native sheets are kept. Unknown media state stays open for a later check. Archiving can discard unsaved forms; choose Off to retain live pages. Library → Archive → Quick Browse can restore into a compact window or a Space.
- Quick metadata and remembered choices are encrypted in their owning profile. Private quick windows use their owner’s temporary WebKit storage and never write normal metadata. Incoming external links always use the normal owner.

The document format advances to **3** inside the existing `session-v2.sealed` file. It uses the same Keychain key. A 0.5 reader refuses the newer format without rewriting it; use 0.6 or newer to reopen that metadata. The earlier encrypted `session.sealed` migration copy remains untouched and may contain older URLs/history. Clearing current history does not erase that retained copy or system backups.

Automated checks cover migration/identity repair, hostname routing, profile isolation, failed-save/Unlock recovery, popup/Peek ownership, window lease ordering and archive policy. Actual loopback WebKit pages verify unsaved forms, history, scroll and separate website accounts through handoff. Hidden native-controller checks cover close/recovery/teardown; they do not establish visual or animation correctness. Native screenshot, resizing, animation, keyboard, device-permission, minimum-OS and quarantined-install testing remain pending. Full Arc parity, Safari-equivalent speed and complete security are not claimed.

The app is ad hoc signed, not Developer ID signed or notarized by Apple. macOS may block it. Keep system security enabled; if blocked, build from source or wait for a notarized release. This remains an early preview. `SHA256SUMS.txt` detects changed download bytes; it does not establish developer identity.
