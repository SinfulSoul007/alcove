# Alcove 0.19.2 preview

Command-Q works from clean Library, Settings, Site Search, Link Routing, Appearance, Profiles and Updates panels. Unsaved routes, search shortcuts and Space names remain protected until saved or discarded. Ending or reusing a native sheet restores its normal termination policy. Boost drafts, native confirmation dialogs and accepted save/print operations retain their existing protection.

The browser remains a universal macOS 14+ preview using system WebKit. Encrypted metadata format 8 is unchanged, so existing tabs, folders and window layouts carry forward. Quit Alcove and keep a backup before replacing its app.

This download is ad hoc signed, without Apple Developer ID signing or notarization. macOS may block it. Keep system security enabled; building from source is an alternative. A changed unsigned build can prompt for macOS Keychain approval.

Full original uBlock Origin and complete Chrome-extension compatibility are still under development. The separate custom WebKit engine is being qualified and is not bundled in this preview. This is an incremental browser update, not the completed full browser release.
