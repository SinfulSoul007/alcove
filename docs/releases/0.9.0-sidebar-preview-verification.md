# Alcove 0.9 sidebar preview verification

This checkpoint implements tab/window closure and saved-tab organization. Cmd-W closes a visible panel or Peek first, then the focused page; an empty current-Space window closes while the application continues running. Saved pins and other Spaces remain saved. Favorites, Pinned and Today have independent scroll regions. Bookmarking adds a Library entry and pins the source page without reloading it. Empty folders persist per Space, including migrated older folders after their last tab moves out. Folder removal keeps its tabs pinned.

The live test also caught a newly selected WebKit page remaining blank until another layout change. The native host now fits an attached/replacement page immediately and follows viewport resizing without waiting for deferred constraints.

## Verification

- Complete frozen suite: **1995 PASS, 0 FAIL**, no compiler diagnostics.
- The suite includes 45 organization checks and 43 layout/rendering checks, including failed-save atomicity, encrypted empty-folder relaunch, legacy migration, profile/private isolation and live form preservation.
- Actual native scroll regions and footer fit at 1260×820, 960×494 and 760×400, with text scales 1.0 and 1.35 (the supported maximum). Scrolling Today leaves Favorites/Pinned geometry and scroll offsets unchanged.
- Native CUA: first/second Cmd-T pages render before any layout workaround; tab switching, tab closure, folder creation/movement/rename/removal preserve a typed local form. Both pinned-only and initially blank private windows close with Cmd-W while Alcove remains running. Temporary private windows were closed and the saved normal window restored.
- Optimized arm64 and x86_64 builds share all **159 unchanged input files** with the full suite. Source/input manifest fingerprint: `8b7a7bfe2892ad8f2a0388aeb85f2ee036fc4e400eca5108879e7bb7e35470de`.
- Exact version 0.9.0/build 16 Info metadata, declared macOS 14 minimum, ad hoc signature, hardened runtime and the existing six sandbox entitlements verified. No JIT, additional entitlements or dependencies added.
- Universal ZIP structure/executable permissions/no local sessions or keys verified. The DMG was verified, mounted read-only, and its app executable/Info compared with the packaged source. Both architecture slices verified independently and in the universal app.

## Limits

This is an unsigned/ad hoc preview, without Developer ID signing or Apple notarization. Runtime testing here used the development Mac; Intel and macOS 14 hardware runs remain outstanding. Developing 0.9 uses metadata format 5, which public 0.8 cannot read; protected encrypted-session and app rollback copies were retained before the local update. Re-signing the stable test identity changes embedded signature bytes, so source-package and installed-test executable hashes are recorded separately.

Native WebExtension hosting is a development checkpoint. Its management UI, optional permission flows, private client adapters and complete native erasure/reopen workflow remain unfinished. This verification does not claim complete Arc parity, a security audit or Safari performance parity.
