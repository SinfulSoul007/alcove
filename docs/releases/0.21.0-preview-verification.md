## Changes

View → Show Reader prepares supported HTML articles locally using pinned Mozilla Readability in a private extraction world. A separate ephemeral renderer disables article JavaScript, remote content and extension attachment. Light/sepia/dark, typography/width, Find and zoom apply to the article while preserving the original document/form/scroll. Reflow preserves the visible passage. Closing, navigation, profile clear and ownership transfer revoke the corresponding Reader session. Print/save commands explicitly target the original page.

File → Export Bookmarks HTML… exports the captured normal profile's Favorites, pins/folders and remaining library bookmarks, retaining saved pin URLs and names. Today, history, other profiles, cookies and private windows are excluded. The native save flow explains that the resulting file contains readable titles and URLs outside encrypted storage. Snapshot/window/profile checks and accepted-output tracking cover stale controls, close and Quit.
