## Behavior

View → Show Reader prepares supported HTML articles locally using pinned Mozilla Readability in an isolated extraction world. A separate ephemeral renderer disables article JavaScript, remote content and extension attachment. Light/sepia/dark, typography/width, Find and zoom preserve the original live document and its form/scroll state. Appearance changes preserve the visible text passage. Navigation, close, profile clear and ownership transfer revoke the article. Print/save explicitly target the original page. Unsupported content explains its limits. See [Reader verification](../reader-mode-verification.md).

File → Export Bookmarks HTML… exports the captured normal profile's Favorites, pins, nested/empty folders and remaining library bookmarks, retaining saved pin addresses and names. Today, history, cookies and other/private profiles are excluded. The save flow explains that exported titles and URLs are readable outside metadata encryption. Captured snapshot/window/profile checks and accepted-output tracking cover cancellation, stale controls, close and Quit. See [bookmark export verification](../bookmark-export-verification.md).

Broader website/Reader/importer compatibility, live dialogs and visual/keyboard/animation/accessibility QA, quarantined installation, macOS-14 and real Intel hardware, performance/energy and independent security review remain open.
