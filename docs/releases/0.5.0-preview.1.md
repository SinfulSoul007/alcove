# Alcove 0.5.0 — Unsigned Preview

Download the universal DMG and drag Alcove.app to Applications. The ZIP contains the same app. Both support macOS 14 or newer on Apple Silicon and Intel.

This build adds named browser profiles. Each profile has separate website logins and storage, Favorites, bookmarks, history, recently closed tabs and archive. Multiple Spaces can share a profile. Existing Spaces keep the default website store so their current logins remain available.

- Manage profiles from the Alcove menu, Settings or a Space’s menu. Create, rename and assign profiles, and delete a named profile after moving its Spaces elsewhere.
- Favorites stay with their profile when a Space changes profile. Opening a shared Favorite keeps the current Space and preserves its live page.
- Cross-profile tab moves and Space assignments warn before reloading pages. Cookies never move; unsaved forms and page state cannot be transferred.
- Profile-specific website clearing and deletion record recoverable pending operations. An interrupted operation stays paused until you retry it.
- Private windows retain temporary website storage and do not write the normal profile registry or browsing metadata.

The metadata upgrade uses the existing Keychain key and writes `session-v2.sealed`. The previous encrypted `session.sealed` is retained untouched for recovery and older previews. Older previews cannot overwrite the new profile registry, but edits made in them after migration are not merged. The retained migration copy may include older URLs/history; clearing the current history does not erase that copy or system backups. Unknown future metadata versions stay locked rather than being overwritten.

The 0.4 sidebar, themes, customization, welcome setup and opt-in update checks remain available. Full Arc feature parity and Safari-equivalent performance are not claimed. Source and real WebKit integration checks cover profile storage separation, migration, failure/retry, popup/Peek ownership and Favorites lifecycle. Native visual/animation/keyboard testing of the latest UI remains pending, along with broader website, minimum-OS and quarantined-install testing.

The app is ad hoc signed, not Developer ID signed or notarized by Apple. macOS may block it. Keep system security enabled; if blocked, build from source or wait for a notarized release. This is an early preview rather than a stable daily-driver recommendation. `SHA256SUMS.txt` detects changed download bytes; it does not establish developer identity.
