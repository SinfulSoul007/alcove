## Implemented experience

- Original finite vector lettering over a soft gradient precedes setup. Skip, Return and Escape leave only the greeting; Reduce Motion or disabled interface animations bypass it. No fonts, images, account or audio are downloaded for the introduction. Replay is under Alcove → Welcome to Alcove….
- CmdW closes a panel/Peek, focused tab, then an empty window; the app remains running. Favorites, Pinned and Today have independent scroll regions. Empty folders persist, tabs can move into them, and removing a folder keeps its tabs pinned.
- The Extensions manager accepts reviewed folders, ZIP, CRX3 or Chrome Web Store ID/link. Source/publisher/digest, unsupported APIs, permissions and private scope are visible before approval. Enable/disable, options, permission editing, package updates, removal and interrupted cleanup use the captured owning profile.
- Native actions, popups, keyboard commands and tab context menus keep their real page/account ownership. Private association is explicit and uses consent for reload; private website cookies and forms are separate from the spanning extension's shared settings.
- Failed or unavailable extension setup presents source-bound recovery over the mounted website in main, split, Quick and Peek. Original safe GET/HEAD requests retain their headers. POST forms, embedded frames, downloads and extension pages are not replaced with top-level GETs; recovery asks the user to submit again from the kept page. macOS 14 cannot silently bypass an enabled saved extension. Continue Without is session-only and leaves saved approvals unchanged.

## Review corrections

One final source review found three Important defects and one Minor defect. The author verified each and made one RED-to-GREEN fix pass, followed by the combined gate above. No Critical defect was substantiated; this is source review, not an independent security audit.

| Finding | Result and evidence |
| --- | --- |
| Unavailable native APIs could silently bypass enabled extensions | Non-native recovery host binds actual profile/controller/store, blocks visibly and requires explicit session-only bypass. Catalog/epoch changes invalidate bypass. Owned native control tests pass. |
| Recovery controls were not connected to production and URL-only replay changed request semantics | All production website hosts show immutable source/problem-bound native controls without replacing their WKWebView. Real POST, header, frame, download, stale-button, timeout and shutdown regressions pass. |
| Shelf-only Favorite operations could use the selected foreign account | Owning-profile transactional unpin/activation materializes the same UUID before shelf removal and selects the exact owning Space/tab; the other account's form stays mounted. The failing-before/passing-after adapter suite has 27 checks. |
| Duplicate ignored Quick/reader/mute configuration | Unsupported targets/options are rejected before creating a tab. Supported primary duplication remains available. |

Additional reviewed boundaries retained their tests and conservative behavior: bounded archive/CRX parsing and publisher identity; owned staging/publication; credential-free bounded download transport; cancellation and failed-save atomicity; controller identity repair and future-format refusal; native temporary grant provenance/expiration; private data/controller isolation; durable uninstall/clear/delete and retained-page barriers. A same-user process changing files after integrity checks is not certified as an adversarial boundary. A blocked native erase may retain its worker/lease until it finishes; filesystem secure erasure is not promised.

## Runtime evidence and limits

Dedicated VM testing used macOS 26.6.2 on Apple Silicon with system WebKit 21624.5.1.11.3. Live checks covered greeting/skip/replay/animation-off, page rendering, sidebar resize/reset/short layout, CmdW and empty-window behavior, compact minimum layout, picker/manager keyboard handling, source-window closure, native options/menu form preservation, private reload consent/cancellation/detachment, extension removal and unchanged-binary relaunch. OS Reduce Motion and full VoiceOver testing remain separate from the implemented branches and owned controls.

The exact uBlock Origin Lite 2026.1110.1816 package, store ID `ddkjiahejlhfcafbddmgiahcphecmpfh`, SHA256 `bf52514bd012b1ce2b1d4bd65dd1c74cd17e666126939ad86b634428e20e5813`, passed default request blocking, install review, popup/dashboard, permissions, disable/re-enable, relaunch and removal in the VM. Its `offscreen` and `userScripts` APIs are unavailable. Full uBlock Origin is unsupported. This does not certify every Lite filter/version or arbitrary Chrome extension.

Older system WebKit needs a normal-profile controller workaround for request rules. A backgroundless static blocker exposed the corresponding idle-first-page case; its real network control and native cleanup passed on the older CI engine (60 assertions). Private request blocking is refused before changing pages below loaded system WebKit 624.1.16, preserving approvals and private browsing. See [engine evidence](../research/webkit-request-blocking.md). There is no normal/private controller sharing to bypass the engine defect.

Remaining restrictions include private extension options/tabs, split-private runtimes, extension-to-website opener-preserving popups, source-less optional permission callbacks, new normal-window creation, exact Chrome tab ordering/index parity, native messaging, devtools, side panels and sandbox pages. Shared spanning-extension settings/permissions are disclosed; approved extensions themselves may retain or transmit private information.

The downloadable app is ad hoc signed, without Developer ID or notarization. Changed unsigned code can still prompt for Keychain approval; unchanged-binary relaunch did not. Protection was not weakened and there is no plaintext fallback. No Keychain/session/profile material is included in the installers. Gatekeeper/quarantined-install, Intel hardware and macOS 14 hardware verification remain open.

Version 0.9 uses encrypted metadata format 5; public 0.8 cannot read it. Quit before replacing the bundle and retain a backup. Signing trust, authenticated updates, broader website/vendor compatibility, accessibility, password-manager integration, bookmark import/export, media controls, sync, Easels/assisted workflows, performance/energy measurement and an independent security audit remain work in the [full acceptance inventory](../goal/acceptance.md).
