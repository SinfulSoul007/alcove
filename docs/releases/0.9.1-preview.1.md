# Alcove 0.9.1 — Unsigned Preview

This patch repairs native fullscreen navigation and Quick Browse address focus. It carries forward the original animated opening, Spaces/themes, Favorites, pinned folders and experimental extensions from0.9.

- Fullscreen keeps the browser's navigation row visible and restores normal native-button alignment on exit.
- New Quick Browse windows focus their address field. CmdL, Open Location and Enter an address select the URL reliably, including repeated requests. Find keeps its query editor; background and closed windows cannot claim another window's focus.
- Focus/fullscreen transitions keep the same website and unsaved form input. No saved-data format change from0.9 is introduced.

Universal macOS14+ app for Apple Silicon and Intel. The DMG contains Alcove.app and an Applications shortcut; the ZIP is an alternative. This is an ad hoc signed preview without Developer ID or notarization. Keep macOS security enabled. Changed unsigned builds can prompt for Keychain approval; protected storage has no plaintext fallback.

Encrypted metadata format5 is unchanged from0.9;0.8 cannot read it. Quit Alcove and keep a backup before replacing its app.

Full uBlock Origin remains unsupported. Separate uBlock Origin Lite has limited tested compatibility. Native extension APIs require macOS15.4+, and private request blocking additionally requires a fixed system WebKit624.1.16 or later. See the repository's extension compatibility and full-browser acceptance records for the remaining feature, hardware, accessibility, performance and security work. Full Arc parity and Safari-equivalent speed are not claimed.

Validation and artifact digests are recorded separately after the exact-source local/CI/public download gates. This file does not establish a completed publication by itself.
