# Full browser acceptance ledger

The active user goal remains: a fully built browser with regular updates, Arc's full feature set and visually correct behavior, extensive themes/customization, a polished first-launch animation, and a smooth sidebar. A passing preview or a partial feature list does not complete this goal.

Published 0.6.2 artifacts and public update selection have been verified. Releases 0.5 and 0.6 add isolated profiles, profile-owned Favorites and Quick Browse. Release0.6.1 adds native chrome alignment, responsive controls and sidebar interaction/cancellation fixes; 0.6.2 adds native page output and accepted-output/Quit handling. The full goal remains in progress.
