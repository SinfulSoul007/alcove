# Full browser acceptance ledger

The active user goal remains: a fully built browser with regular updates, Arc's full feature set and visually correct behavior, extensive themes/customization, a polished first-launch animation, and a smooth sidebar. A passing preview or a partial feature list does not complete this goal.

The current public release is [0.21.0-preview.1](../releases/0.21.0-preview-verification.md), exact source `57a11f4462204eb380e28a9ab37ea1e7638313c9`. It includes Reader and bookmark HTML export. Complete source CI, both optimized architectures, universal ZIP/mounted DMG and public installer hashes passed verification. The production update client authenticated the public 0.20→0.21 offer and installer, rejected a modified installer and reported 0.21 up to date. It remains an ad hoc signed system-WebKit preview, without Apple notarization. The full browser goal remains in progress.

The work records below preserve earlier checkpoints. Historical “pending” statements describe those checkpoints; the current release record supersedes their publication status. Reader and bookmark export are included in 0.21. The separate experimental extension engine and developing website-fullscreen work are not included in this public preview.
